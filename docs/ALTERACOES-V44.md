# Alterações da v44

- Catálogo público com título, capa promocional servida pelo distribuidor, resumo e link oficial.
- A seleção inicial tem **O Príncipe do Egito** e **José: O Rei dos Sonhos**, verificados nas páginas da Universal Pictures At Home. Os links oferecem opções digitais e físicas conforme o mercado. A disponibilidade brasileira e o preço dependem do fornecedor. Adão e Jacó ficam sem indicação até localizar uma oferta oficial específica.
- Retirada da descoberta de filmes pelo YouTube, filtros, aprovação e moderação no painel. A automação do Pages monta o site sem executar buscas ou acessar a chave do YouTube.
- Migração `2026110501` para limpar vídeos, decisões, solicitações e listas legadas no Supabase. O catálogo compartilhado mantém os registros de outros tipos. A RPC pública antiga responde com lista vazia para compatibilidade.
- O botão **Atualizar banco de dados** reutiliza o workflow de manutenção e requer superadministrador.
- Playlists, música, pregações já existentes e a lixeira de conteúdos gerais permanecem disponíveis. A integração com a API do Spotify e uma área de canais de pastores ficam para uma próxima etapa.
- O kit Python é o mesmo entregue na v43. O ZIP contém o script original.

A instalação e a publicação na conta de produção dependem do envio dos arquivos e da execução dos workflows. As páginas oficiais são uma referência para acesso individual. A v44 não trata de licenças de exibição coletiva.
