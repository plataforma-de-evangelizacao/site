# Como atualizar filmes e desenhos sem editar HTML

Primeira publicação: extraia o ZIP e envie index.html, catalogo.txt e .nojekyll para a raiz do repositório. Não envie só o ZIP.

Depois, edite apenas catalogo.txt no GitHub ou no editor de texto do computador e envie esse arquivo atualizado ao GitHub.

Use uma linha por item:
Título | Categoria | https://link-do-conteudo | Descrição opcional

Categorias aceitas: Filmes bíblicos, Filmes cristãos, Desenhos bíblicos, Superação, Canais e sites, Outros.
Não use o caractere | no título. Linhas com # são comentários e não aparecem. Links precisam começar com https://. Links repetidos são ignorados. Título e descrição são exibidos como texto; o catálogo não executa HTML.

O site lê o catálogo ao abrir e a cada cinco minutos enquanto estiver aberto. A publicação do GitHub pode levar alguns minutos. Não há pesquisa automática no YouTube nem alteração do catálogo por visitantes.

Para conferir um arquivo antes de publicar, abra o site com ?gerenciar=1 antes do #, por exemplo /site/?gerenciar=1#filmes-desenhos. Selecione o TXT. Isso altera somente a visualização desse navegador; não grava no repositório. Em arquivo HTML baixado, a prévia de importação aparece automaticamente.

O site não acessa pastas do computador sem uma seleção explícita e não transmite o arquivo selecionado. Para todos verem a nova lista, publique catalogo.txt no repositório. Prefira links de canais oficiais ou fontes autorizadas. Você pode enviar sua lista ao ChatGPT para organizar nesse formato.
