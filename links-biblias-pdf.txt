COMO USAR O DRIVE

- Baixe primeiro os arquivos que puder redistribuir conforme a licença.
- Preserve o PDF original com autoria, nome da tradução, edição e licença.
- Coloque no Google Drive. Compartilhe somente os arquivos autorizados com acesso de leitura, permitindo o download se essa for sua intenção.
- Teste o link em janela anônima, para conferir se não pede acesso à sua conta.
- Cadastre cada link em dados/biblias-pdf.json no repositório. Troque apenas o campo link, mantendo os demais metadados corretos. Não invente IDs de compartilhamento.
- O site abre o link compartilhado; a tela e a opção de download dependem das configurações do Google Drive. Não é preciso API do Drive para links públicos.
- O upload por navegador no GitHub tem limite de 25 MiB por arquivo (não 24 MB). Git normalmente bloqueia arquivos maiores que 100 MiB; o Drive pode ser usado independentemente do tamanho.
Documentação do GitHub:
https://docs.github.com/pt/repositories/working-with-files/managing-files/adding-a-file-to-a-repository
