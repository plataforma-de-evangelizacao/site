# Comece aqui · PGE v45

1. Guarde um backup do repositório e do Supabase. Use o kit Python da v43.
2. Aplique o ZIP sobre o repositório existente e inclua a pasta oculta `.github`. Preserve `admin/config.json` e as credenciais configuradas na sua conta. Revise o diff antes de enviar para `main`.
3. Acompanhe o GitHub Actions e abra o site publicado. Se ainda não aplicou a limpeza da v44, siga o guia da v44 para cancelar buscas antigas e executar **Atualizar banco de dados**. Essa limpeza remove o acervo antigo. Faça o backup antes.
4. Em **Administração → Parceiros e comunidades**, confirme que a lista de parceiros autorizados começa vazia. Use **Cadastrar novo parceiro** depois de obter confirmação e autorização para divulgar. Se o cadastro não estiver habilitado, confira a permissão de escrita e sincronize o banco do painel.
5. Siga [o roteiro](docs/TESTES-V45.md). A v45 mantém a versão de backend `2026.11.05.1` da v44.
