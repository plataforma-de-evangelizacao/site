Preparação inicial — apenas uma vez

Cadastre os dois segredos de integração no GitHub. Ao subir este pacote, a preparação do Supabase é automática: banco, função e configuração do disparo.

  1. SUPABASE_ACCESS_TOKEN: token de gestão do Supabase limitado ao projeto (database_migrations_write, edge_functions_write e edge_functions_secrets_write).
  2. GITHUB_DISPATCH_TOKEN: token do GitHub, somente este repositório, Actions: Read and write.

Não cole segredos nesta página. Os Secrets SUPABASE_URL e SUPABASE_SERVICE_ROLE_KEY já existentes são preservados.

Criar token de integração do Supabase ↗Abrir Secrets do GitHub ↗Preparação inicial no GitHub ↗

Se os segredos foram cadastrados depois do envio dos arquivos, abra a preparação inicial no GitHub e use Run workflow uma vez. Depois, use os botões deste painel.

O botão aplica somente atualizações versionadas incluídas no código. Não há campo para executar SQL livre.
